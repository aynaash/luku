A page that looks fine and is not

Every value on this page is reasonable in isolation. The card padding is a round number, the gap is a round number, the grey is a perfectly ordinary grey, and both buttons are buttons. None of it is wrong until you compare one measurement against another, which is the whole reason this check has to run against the rendered page rather than against the source that produced it. A source linter sees a padding token and a gap token and has no opinion, because in the source they are simply two different constants.
